01 — 시작하기

  • 가입에는 초대 코드가 필요해요. 코드를 받았다면 첫 화면 → 시작하기 → Google 로그인 → 코드와 핸들 입력.
  • 핸들은 곧 주소예요 — luvinfo.me/핸들. 영문 소문자·숫자 2~20자, 나중에 바꾸기 어려우니 신중히!
  • 화면 오른쪽 위: 📱 미리보기 · ✎ 편집 · 로그아웃 버튼이 있어요.

02 — 장(페이지) 만들기

성향글은 장을 넘기며 읽는 구조예요. 장은 두 종류:

  • 보통 장 — 블록을 쌓아 만드는 장. ＋ 버튼으로 블록을 추가하고 ↑↓로 순서를 바꿔요.
  • HTML 장 — 코드를 통째로 붙여넣는 장. 📄 HTML 파일 불러오기로 파일째 올릴 수도 있어요. 이 장에서는 위 머리글이 자동으로 숨겨져요(체크로 다시 켤 수 있음).
  • 장 넘김은 화살표·이름 알약·점 3종 중 🎨 꾸미기에서 선택.
  • 장 비밀번호 — 장 편집에서 비번을 넣으면 그 장만 잠겨요(대문 비번과 별개).
  • 장 제목 꾸미기 — 제목 디자인 5종(꾸미기) + 장마다 제목 이미지(위/아래 위치 선택).

03 — 블록 9종

글자유 입력. 서식: **굵게** ==형광== __밑줄__ ~~취소~~ · 구분선 --- · 접은 글 {접기:제목}…{접기끝} · 사진 [사진1]
프로필사진(원/네모, 좌/우)+닉네임+계정+소개 — 파츠별로 켜고 끄기, 사진은 드래그 조정
갤러리여러 장 업로드, 2·3·4열/슬라이더 선택, 사진마다 위치 조정
음악곡 제목+아티스트(+mp3 링크면 재생 가능)
스티커이미지 여러 개를 크기·기울기 다르게 흩뿌리기
배너아래 04 참고
링크라벨+주소 → 「→ 라벨 ↗」 목록
인용구기억하고 싶은 문장 + 출처
디데이라벨+날짜 → D-30 / D-DAY / D+18 자동 계산
모든 블록은 ✎에서 카드 켬/끔 · 모서리 · 투명도를 따로 정할 수 있고, 장 전체 통일 옵션도 있어요.

04 — 배너 교환

러브인포끼리는 핸들만 넣으면 배너가 걸려요:

  • ✎ 편집 → ＋ 배너 → 상대 핸들 입력 → 핸들로 추가 → 확인 → ✓ 저장
  • 상대가 🎨 꾸미기의 내 배너(220×60 권장)에 올려둔 이미지가 자동으로 떠요. 없으면 홈 제목이 글자 배너로 나와요.
  • 서로 걸면 배너에 ♥가 자동으로 붙어요 — 맞배너 표시!
  • 러브인포 밖 사이트는 이미지+주소를 직접 넣는 외부 배너로.

05 — 꾸미기

  • 프리셋 10종 — 화이트·다크·다이어리·파스텔·모노·글래스·미드나잇·포레스트·레트로 창·VHS. 프리셋은 시작값이에요 — 고른 뒤 색·폰트를 얼마든지 바꿔도 돼요.
  • 머리글 — 글/이미지+글/이미지만/없음. 이미지는 가로 1200px·비율 3:1(예: 1200×400) 권장, 슬라이더로 위아래 위치·확대·높이 조절.
  • 배경 이미지+덮임 정도, 파비콘(탭 아이콘), 장 번호 표시/숨김.
  • 직접 CSS — 아는 사람용. 화면이 깨지면 주소 뒤에 ?nocss=1을 붙여 들어와 지우세요.
  • 러브로그에서 가져오기 — 러브로그 핸들을 넣으면 색·폰트·머리글·파비콘·배경·대문(이미지·문구)을 겹치는 만큼 가져와요. 대문 비밀번호는 안 가져오니 러브인포에서 새로 설정!

06 — 저장 규칙 (중요!)

  • 편집 창의 확인 = 화면에만 반영 / 하단 ✓ 저장 = 서버에 진짜 저장. 저장 안 하고 닫으면 날아가요!
  • 쓰던 글은 자동 임시저장돼요 — 실수로 닫아도 다시 열면 복구를 물어봐요.
  • 🎨 꾸미기 맨 아래에서 백업(JSON) 내보내기/복원 가능. 큰 수정 전엔 백업 추천!

07 — 기타

  • 문의 — 아무 홈이나 맨 아래 ✉ 문의. 보낸 문의와 답변은 같은 창에서 확인.
  • 대문 — 입장 화면(이미지+문구+비밀번호)을 켤 수 있어요.
  • 홈 삭제 — 꾸미기 맨 아래. 되돌릴 수 없으니 신중히.
