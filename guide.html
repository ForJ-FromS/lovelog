LOVELOG 사용 안내

지인들을 위한 갠홈 서비스 — 처음 오신 분은 위에서부터 순서대로 읽으면 됩니다.

01시작하기

첫 화면에서 구글 계정으로 로그인한 뒤, 주소(영문 소문자·숫자·하이픈 2~20자)와 홈 이름을 정하면 내 홈이 바로 만들어집니다. 초대코드를 받았다면 코드 칸에 함께 입력하세요 — 코드가 필요한 시기에는 입력칸이 자동으로 뜹니다. 가입 시 1차 핸들(초대해 준 분의 러브로그 주소) 입력이 필요하며, 1차가 미리 지정된 초대코드로 가입하는 경우에는 비워도 됩니다.

내 홈 주소는 luvlog.me/핸들 — 예를 들어 핸들이 jeste면 luvlog.me/jeste입니다.

글 하나하나에도 고유 주소가 생겨서 트위터 등에 바로 공유할 수 있습니다.

친구 홈은 주소로 바로 방문하면 되고, 오른쪽 위 IN으로 로그인하면 방명록·댓글을 남길 수 있습니다.

02화면 구성

내 홈은 두 가지 형태 중에서 고를 수 있습니다 (꾸미기 → 테마·레이아웃 → 홈).

위젯 그리드형 — 헤더 아래 위젯들이 카드로 배열되고, 중앙에 고정글과 최신글이 뜹니다. 대문 느낌.

클래식 블로그형 — 헤더 아래 바로 글 목록이 펼쳐지는 블로그 구조. 로그 위주라면 이쪽.

  • 카테고리는 상단 알약 바와 사이드 위젯 중 원하는 방식으로 표시하고, 모양 4종(기본 목록 · 알약 · 글씨만 · 네모) 중 고를 수 있습니다 — 어느 위치에서든 똑같이 적용돼요.
  • 사이드바는 왼쪽 / 오른쪽 / 양쪽 중 고를 수 있고, 홈 화면의 기둥도 이 설정을 따라갑니다.
  • 내 홈을 편집하려면 오른쪽 아래 ⠿ (위젯 편집) 버튼을 먼저 누르세요 — 켜져 있는 동안만 위젯 드래그·↑↓ 이동·스티커 배치가 됩니다. 평소에는 내 홈도 방문자처럼 편하게 구경할 수 있어요.

03글쓰기

오른쪽 아래 ✎ 버튼, 또는 각 게시판 상단의 ✎ WRITE로 글을 씁니다. 게시판에서 누르면 그 카테고리가 자동 선택됩니다.

글에 걸 수 있는 옵션

  • 비밀글 — 비밀번호를 걸면 내용이 암호화 저장됩니다. 비밀번호는 잊으면 복구가 안 됩니다!
  • 🔏 비공개 — 나만 볼 수 있게 저장(목록에도 나만 보임). 글 화면의 [공개로 전환]으로 언제든 공개. 초안·소장용 글에.
  • 고정글 — 홈 상단에 고정 카드로 뜹니다.
  • 📅 작성일 — 옛 로그를 옮겨 적을 때 그 날짜로 발행하면 목록에서도 그 날짜 자리에 정렬됩니다(수정에서 날짜를 바꾸면 그 자리로 이동).
  • 🤝 이웃 공개 글 — 글쓰기에서 이웃 공개를 켜면 그 글은 서로 이웃(배너·이웃 홈 위젯에 서로 등록한 사이)에게만 보입니다. 나만 보는 🔏 비공개와 전체 공개 사이의 중간 단계예요.
  • 인용 상자 모양 — 테마 · 레이아웃에서 기본(세로선) / 따옴표 / 편지지 중 고를 수 있습니다.
  • 💬 대화(말풍선) 서식 — [톡:이름1/이름2] 줄과 [/톡] 줄 사이에 "이름: 대사"를 줄줄이 쓰면 말풍선 대화로 보입니다. 첫 인물이 왼쪽 · 둘째가 오른쪽, 이름 없는 줄은 가운데 지문이 돼요. 이름 뒤에 =#색상을 붙이면 그 사람 풍선에 색이 입혀지고(글자색 자동), 툴바의 💬 버튼을 누르면 설정 팝업에서 모양(기본 / 메신저 흰 박스 / 무전 로그) · 창 너비 · 좌우 풍선색 · 인물별 이름 · 색 · 프로필 사진(위치 조절 창 지원)까지 정해서 넣을 수 있고, 〈프리셋 저장〉하면 다음 글에서 [톡@프리셋이름] 한 줄로 재사용됩니다. 페어가 여럿이면 프리셋을 여러 개 만들어두세요.
  • 🧩 HTML 블록 — 일반 글쓰기 안에서 특정 부분만 HTML로 넣고 싶으면 [html] 줄과 [/html] 줄 사이에 코드를 쓰세요. 그 바깥은 평소처럼 서식 문법이 적용되고, 블록 안은 코드 그대로 보입니다(글 전체가 HTML이면 기존 HTML 모드를 쓰는 게 편해요).
  • ⏰ 예약 발행 — 예약을 켜고 시각을 정하면, 그때까지 방문자에게 숨겨졌다가 시각이 되면 자동으로 공개됩니다. 주인에게는 ⏰ 표시와 함께 항상 보여요.
  • 🏷 태그 — 제목 아래 태그 칸에 페어명·시리즈명 등을 달면(쉼표/엔터, 여러 개 가능) 게시판 위에 태그 알약이 모여서 눌러 좁혀 볼 수 있어요. 한 카테고리에서 여러 페어·AU를 나눌 때! 글 아래 태그를 누르면 그 태그 글만 모아 보고, 이미 쓴 태그는 입력할 때 자동으로 떠요. 카테고리 탭에서 자주 쓸 태그를 미리 등록해두면 글 쓸 때 ＋ 버튼으로 한 번에 붙습니다.

엔터를 여러 번 치면 빈 줄이 그만큼 그대로 들어갑니다 — 문단 사이 여백을 자유롭게 조절해 보세요. 쓰던 글은 자동으로 임시저장됩니다 — 실수로 창을 닫거나 새로고침해도, 다시 글쓰기를 열면 이어서 쓸지 물어봐요(발행하면 사라지고, 비밀번호는 저장되지 않습니다).

본문 서식

  • 글자를 드래그로 고르고 툴바의 B · I · U · S · H를 누르거나, **굵게** *기울임* __밑줄__ ~~취소선~~ ==형광펜==처럼 직접 감싸도 됩니다.
  • 문단 정렬(☰▾ — 가운데·오른쪽·양쪽·들여쓰기) · 구분선(―▾ — 가는 선·굵은 선·점선·빗금·◆ 장식) · 목록(1.≡ 순서 / •≡ 점) · 글자를 고른 뒤 쓰는 글자 크기(A↕)와 글자 색.
  • ▸ 접은 글 — 툴바 ▸ 또는 [접기:제목] … [/접기]로 감싸면 읽는 사람이 눌러서 펼치는 상자가 됩니다. 스포일러·긴 TMI에 좋고, 접은 내용은 목록 미리보기(발췌)에도 안 나와요.
  • ❝ 인용 상자 — 문단 각 줄 앞에 > (툴바 ❝)를 붙이면 포인트색 선이 있는 인용 상자.
  • 🔗 글자 링크 — [보일 글자](https://주소)(툴바 🔗)로 문장 속 글자에 링크.
  • 본문 사진 — 사진을 첨부하고 본문에 [사진1] [사진2]를 쓰면 그 자리에 들어갑니다. 본문 칸에 사진을 붙여넣거나(Ctrl+V) 끌어다 놓으면 바로 첨부되고 커서 자리에 [사진N]이 들어가요. 유튜브 주소는 한 줄에 붙여넣으면 카드로 예쁘게 박혀요.

HTML 모드

체크하면 본문을 HTML 코드 그대로 저장합니다 — 채팅 로그 백업 등 스타일 살려 올릴 때. 코드를 붙여넣는 대신 📄 HTML 파일을 그대로 업로드해도 되고, 코드 위·아래에 쓴 일반 텍스트는 줄바꿈까지 그대로 보입니다. 화면을 가득 붙잡는 형태의 로그는 홈이 밀리지 않게 자동으로 액자에 격리되고, 일반 HTML 글엔 홈 커스텀 CSS가 그대로 적용됩니다.

메모형 글 (팝업 작성)

카테고리 타입을 메모로 만들면 짧은 글들이 카드 그리드로 모입니다. 메모 게시판에서 WRITE를 누르면 팝업 작성 창이 떠요 — 제목(비우면 첫 줄로 자동)·서식 툴바·사진 4장·🔒 비밀·🔏 비공개·💬 댓글 설정까지 팝업에서 끝나고, 수정도 팝업으로 열립니다(비밀 메모 수정만 글쓰기 화면). 사진 있는 메모는 카드 위에 썸네일이 떠요. 메모는 💬 댓글이 기본으로 꺼져 있으니 받고 싶은 메모만 💬를 켜세요.

읽기

  • 글에 이미지가 있으면 목록에 썸네일이 자동으로 붙고, 글 하단 ‹ 이전 / 다음 ›으로 연달아 읽습니다.
  • 글을 연 뒤 ✎ 수정 — 처음 쓴 그대로 열립니다. 비밀글 수정은 비밀번호를 다시 입력해야 저장.
  • 글 아래 링크 복사로 그 글의 주소를 바로 공유. ♡ 공감으로 마음을 남길 수 있어요(다시 누르면 취소).

04꾸미기

오른쪽 아래 ✦ 버튼이 꾸미기 대시보드입니다. 왼쪽 메뉴 순서대로 소개할게요.

위젯 구성

넣을 수 있는 위젯들입니다. 이미지 위젯은 여러 개 넣을 수 있어요.

글 · 기록

  • 최신글 블록 — 최근 글 목록. ✎에서 개수, 특정 카테고리만 골라 보이기(여러 개 두는 것도 가능), 앞머리 모양(◈ 대신 ✦ ♥ 등 아무 이모지·문자)을 정할 수 있어요. 최신글을 아래로 내리고 싶다면 이 위젯을 추가하는 것이 열쇠 — 추가하는 순간 중앙 상단에 고정돼 있던 최신글 영역이 풀려서 드래그로 어디든 옮길 수 있습니다(공지·인용구를 그 위로 올릴 때도 이 방법).
  • 📌 고정글 — 고정글만 따로 두는 카드. 최신글 블록의 '고정글 함께 표시'를 끄면 완전히 분리됩니다.
  • ★ 대표글 — 추가하면 글 목록 제목 옆에 ☆가 생겨요. 눌러서 켠 글을 모아 N개 전시(글쓰기 화면의 체크로도 지정). 앞머리 기호도 자유.
  • 타임라인 — 연표 위젯. 항목마다 날짜·제목·로그, 라인·마디 카드·담백 3디자인, 점 모양 이모지 자유 지정, ✨움짤·↻반복·최대 높이 지원.
  • 공지 — 제목+내용 고정 카드. / 글 — 제목+자유 텍스트, 고정 카드 느낌 없이 담백하게.
  • 인용구 — ✨ 움짤 효과(타이핑)를 켜면 문장이 한 글자씩 나타나요.

전시 · 연출

  • 채팅로그 — 좌우 대사 말풍선. 디자인 3종, 대사별 프사, 말풍선 색·글씨색·글꼴·글자 크기 조절. ✎에서 ✨ 움짤 효과를 켜면 말풍선이 순서대로 떠오르고, ↻ 반복은 다 뜬 뒤 처음부터 다시. 최대 높이(px)를 정하면 긴 채팅은 스크롤(사이드 360px, 넓은 자리 440~480px 적당 — 비우면 전체 표시).
  • 단말기 — 핸드폰 잠금화면처럼 알림 배너가 쌓이는 위젯. 디자인 4종(OLED 미니멀·프로스트 글래스·관제 단말·레트로 창 — 윈도우 98풍 파란 타이틀바). 알림은 원하는 만큼, 관제 단말은 헤더 라벨에 세계관 이름 자유. 색은 직접 고르거나 '기본으로'를 누르면 홈 테마색, 케이싱(테두리)은 메탈/단색. 높이를 비우면 알림 개수만큼(삐삐st), 정하면 고정+스크롤. 시계 온오프, 우상단 ✕로 닫으면 📱 버튼으로 숨음. ✨움짤·↻반복 지원.
  • 이미지 — 사진 한 장+제목을 LOVE처럼 직접 입력.
  • ☑ 투두리스트 — 할 일 목록 위젯. 디자인 4종(기본 · 메모지 · 모눈 노트 · 리본 편지지)은 출발점이고 — 제목 이모지 · 제목/할 일 각각의 폰트(고딕·명조·손글씨·모노)와 색 · 포인트색 · 부제 줄까지 전부 취향대로 바꿀 수 있어요. 체크·해제는 홈 화면에서 주인이 바로 누르면 저장되고, 방문자에게는 보기만 됩니다. 완료한 항목은 취소선으로, 아래에 진행 수(2 / 5)가 떠요.
  • 페어 인터뷰 — 질문마다 두 인물이 답하는 위젯. 디자인은 말풍선 / 문답(이름: 답) 두 가지. 인물별 이름·말풍선 색·프로필 사진(선택)을 정할 수 있고, 답을 비우면 그 사람 말풍선은 생략됩니다. 질문이 많으면 "처음 N개 + 더보기"로 접어두거나, 한 개씩 넘겨보기(‹ ›)로 카드처럼 넘겨 볼 수 있어요.
  • 캐릭터 / 페어 프로필 — 스킨 7종(기본·아카이브 파일·컬러 프레임·스토리·신분증·트레이딩 카드·메신저 프로필)·템플릿 5종으로 캐릭터 소개 카드를 꾸밉니다. 신분증·트레이딩 카드·메신저 스킨에서는 부제가 각각 직함·LV·상태메시지 자리에 들어가요.
  • 디데이 · 달력 · 해빗 트래커 — 기념일 카운트와 기록 위젯. 디데이는 기본이 첫날=1일(당일 D+1)이고, 항목마다 당일=1일 / 당일=0일을 고를 수 있어요 — 0일을 고르면 시작일을 0으로 세는 방식(당일 D+0)이 됩니다.

연결 · 상호작용

  • 프로필 · 검색 · 카테고리 — 기본 3종. 검색은 제목·본문·태그를 함께 찾습니다(비밀글 본문 제외).
  • 위젯 목록의 표시 버튼을 누르면 홈에서만 · PC에서만 · 꺼두기를 체크로 자유롭게 조합할 수 있어요. 예를 들어 홈에서만+PC에서만을 함께 켜면 PC로 홈을 볼 때만 보입니다. 카테고리의 선택 표시(현재 폴더 강조)는 테마 · 레이아웃에서 기본/연하게/없음 중 고를 수 있습니다.
  • 링크 · 배너칸 — 바깥으로 나가는 목록. 배너칸은 러브로그 홈 걸기 지원(05 참고).

  • 🔒 비밀 댓글 · ↳ 답글 — 댓글에 비밀 체크를 켜면 홈 주인과 작성자에게만 보이고, 댓글의 [답글]로 한 단계 대화를 이어갈 수 있습니다.
  • 📑 목차 — 긴 글에서 큰 글자(18 이상)로만 쓴 짧은 줄이 2개 이상이면 글 상단에 목차가 자동으로 생깁니다. 누르면 그 부분으로 이동해요.
  • 새 방명록 글이 달리면 카테고리 목록의 방명록 이름 옆에 작은 점이 표시됩니다(주인에게만 · 방명록을 열면 사라져요).
  • 남긴 방명록에 주인 답글이 달리면, 그 홈에 다시 방문했을 때 알림이 떠요.

06BGM

BGM 위젯에 유튜브 링크(영상 또는 재생목록)를 넣고 ▶를 누르면 화면 왼쪽 아래 미니 플레이어에서 재생됩니다. 게시판을 옮겨 다녀도 음악이 안 끊기고, 플레이어의 ✕로 끄면 됩니다. 다른 사람 홈으로 가면 자동으로 꺼집니다.

  • 플레이리스트 — ✎ 편집의 [+ 곡 추가]로 여러 곡 등록하면 대표곡부터 순서대로 이어 재생. 곡 목록에서 눌러 바로 넘어갈 수도(곡 전환은 홈 화면에서).
  • 커버 이미지 — 유튜브 썸네일 대신 앨범아트를 직접. [🖼 커버 이미지]=위젯 공통, 곡 줄 끝 🖼=곡별(설정된 곡은 🖼✓, 곡별이 우선). 네 스킨 모두 적용, LP는 판 한가운데 라벨이라 직접 그린 그림을 올리면 진짜 레코드 같아요.

07백업 · 복원 · 이사 · 초기화

  • 꾸미기 → 기본 정보의 백업 — 꾸미기와 글·갤러리를 골라 원본 JSON(비밀글 암호화 원문까지 전부)으로 저장, 읽기용 HTML(브라우저로 열어 그대로 읽기)로도 저장.
  • 복원 — 그 파일로 되돌리기. 복원 직전 현재 상태가 자동 백업되고, 글 복원은 되살리기만(지금 글을 지우지 않음).
  • 이사 — 다른 홈의 백업을 복원하면 사진(사진첩 폴더 포함)까지 이 홈으로 복사돼 새 주소로 이사됩니다(방명록·발도장 기록은 이전되지 않아요).
  • 사진은 링크로 담기니, 가끔 한 번씩 백업해 두면 어떤 일이 있어도 글은 안전합니다.
  • 꾸미기 초기화 — 테마·색만 / 위젯 구성만 / 스티커만 / 사진만 / 전체 중 선택. 글·갤러리·방명록은 지워지지 않습니다. 되돌린 설정은 복구 불가이니 신중하게!
  • 홈 삭제(탈퇴) — 내 주소를 직접 입력하고 두 번 확인하면 홈과 글·사진·방명록이 전부 삭제됩니다. 되돌릴 수 없고 주소는 풀립니다. 구글 계정은 남아 있어 다시 로그인해 새 홈을 만들 수 있어요.

08사진 용량

사진은 모두 전용 저장소에 올라갑니다 — 올릴 때 자동으로 적당한 크기로 줄여주니 큰 파일도 그대로 올리면 되고, 용량 제한은 거의 신경 쓸 필요 없습니다.

예외 두 가지: 움짤(GIF)은 8MB, 대문 영상은 15MB까지 — 원본 그대로 올라가는 항목이라 넘으면 안내가 뜹니다. 움짤은 가로 300~500px 정도로 줄여 올리면 화질도 충분하고 홈이 가볍습니다.

09자주 묻는 것

Q. 꾸민 게 바로 반영이 안 됩니다.

저장 버튼을 눌렀는지 먼저 확인하시고(위젯 구성은 [위젯 구성 저장]), 새로고침해 보세요. 반영에 몇 분 걸릴 때가 있습니다.

Q. 이웃에 넣었는데 이름·사진이 안 뜹니다.

상대가 꾸미기 → 기본 정보의 '내 홈 공개하기'를 켜야 자동으로 뜹니다. 그 전에는 [사진] 버튼으로 직접 이미지를 넣어 쓸 수 있어요.

Q. 스티커가 안 보여요 / 사라졌어요.

꾸미기 → 스티커 탭을 열면 지금 안 보이는 이유(전체 표시 꺼짐 / 모바일 숨김 / 홈에서만 보이기)가 맨 위에 뜹니다. 개별 [숨기기] 상태면 목록에서 흐리게 표시돼요.

Q. 투명 PNG를 올렸는데 배경이 까맣게 나옵니다.

투명 PNG는 투명 그대로 올라갑니다 — 헤더가 하얗게/까맣게 떠 보인다면 테마·레이아웃의 헤더 배경 없애기를 켜보세요.

Q. 비밀글 비밀번호를 잊었어요.

복구할 방법이 없습니다. 암호화 저장이라 운영자도 열 수 없어요.

Q. 헤더가 모바일에서 다르게 잘려요.

헤더 편집의 PC·모바일 미리보기를 보면서 확대·위치 슬라이더를 맞추면 두 화면 모두 예쁘게 나옵니다.

Q. 홈을 아예 지우고 싶어요 / 핸들을 바꾸고 싶어요.

꾸미기 → 기본 정보 맨 아래 홈 삭제로 정리할 수 있습니다. 핸들 변경은 백업 → 홈 삭제 → 새 핸들로 재가입 → 복원(이사) 순서로 하면 글·사진까지 그대로 옮겨져요.

10지켜줄 것

서로의 방명록과 댓글에서 예의를 지켜 주시고, 버그나 바라는 기능은 꾸미기 → 기본 정보 → 문의 · 제보로 보내주세요 — 운영자에게 바로 전달되고, 답변도 같은 자리에서 확인할 수 있습니다. 홈과 관련해 불미스러운 일이 생길 경우 운영자가 조치를 취합니다.
