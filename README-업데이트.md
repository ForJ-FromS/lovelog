# 러브인포 신판 (v9) — 업데이트 안내

블록 조립 에디터를 전면 교체한 버전입니다. 기존 레포에 이 3개 파일을 덮어쓰면 끝:
index.html · app.js · 404.html (firebase-config.js는 기존 것 그대로)

## 바뀐 것
- 편집 모델: 블록 12종 조립 → **장 2종** (보통 장 = 한 칸 자유 입력 / HTML 장 = 코드 통째)
- 보통 장 문법: 빈 줄로 문단, [사진N], {접기:제목}…{접기끝}
- 프리셋 4종: 화이트(기본)·다크·다이어리·파스텔 — 고른 뒤에도 색·폰트 개별 수정 가능
- 머리글 4구성(글/이미지+글/이미지만/없음), 장 제목·번호 표기 자유
- 장 넘김 3종(점/화살표/알약), 편집은 하단 시트(✎ 편집 → ＋새 장 / ＋HTML 장 / 🎨꾸미기 / ✓저장)
- 대문·하트·링크복사·라이트박스 유지

## 기존 데이터
v8(블록)으로 만들었던 페이지는 새 구조로 새로 시작합니다 (하트·대문 설정은 승계).
Firebase 규칙은 그대로 — 재게시 불필요.

파일 3개 덮어쓰기 → 1~2분 대기 → 하드 리프레시(⌘+Shift+R) → 콘솔에 "[LUVINFO] app.js v9 로드" 확인.
