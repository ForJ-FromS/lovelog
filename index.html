        문의 · 제보

        버그, 오류, 바라는 기능을 운영자에게 바로 보내요. 답변이 달리면 여기서 확인할 수 있어요.

        백업

        홈의 글 전체를 내 컴퓨터에 파일로 저장해요. 읽기용 HTML은 브라우저로 열어 그대로 읽을 수 있고, 원본 JSON은 모든 데이터(비밀글의 암호화 원문 포함)를 담아요. 사진은 링크로 저장돼요(파일 자체는 홈에 남아 있어요). 가끔 한 번씩 눌러 보관해 두세요.

        JSON에 담을 것:

        저장 범위 — 꾸미기: 테마·색·폰트·위젯 구성·커스텀 CSS 등 홈의 겉모습 전부 · 글·갤러리: 글 전체(비밀글 포함)와 갤러리. 방명록은 글·갤러리를 담을 때 보관용 기록으로만 함께 저장되고, 복원·이사되지는 않아요.

        복원 (백업에서 불러오기)

        JSON 백업 파일로 되돌립니다. 복원 직전에 현재 상태가 자동으로 한 번 백업되고, 글 복원은 백업 속 글을 되살리기만 해요(지금 있는 글을 지우지 않아요). 방명록은 보관용이라 복원되지 않습니다.
        다른 홈의 백업을 복원하면 사진도 이 홈으로 복사돼요 — 단, 비밀글 속 사진은 복사되지 않아요.
